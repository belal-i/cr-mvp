## CR Laravel-App

### Setting up (locally)

* `composer install`
* `npm install`
* `npm run dev`
* `cp .env.example .env` and enter database credentials
* `php artisan key:generate`
* `php artisan migrate`
* `php artisan db:seed`
* `php artisan serve`
* Browse to http://localhost:8000
* RTFS

### Getting production data into the database.

You need to run the ETL-Pipeline (https://github.com/city-residence/cr-legacy-to-json),
then, replace the fake data file /resources/normalized.json of cr-laravel-app
with the normalized.json (containing real data) generated by cr-legacy-to-json.

The development of cr-legacy-to-json follows closely with this application.
For this reason, you need to make sure to use the right version of cr-legacy-to-json:

Required cr-legacy-to-json version: `v0.3.1`
